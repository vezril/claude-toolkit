# App Store release notes

Turns a version's merged changes into the "What's New" text for the App Store.

## Draft from git

Read the commits since the last release tag, keep only user-visible changes, and write them as short benefit-first lines.

## Translate

When the user asks for other locales, translate the approved English notes into each requested locale, keeping product names in English.

## Fit the limit

When the notes run long, cut them to fit the 4,000-character App Store limit and the 170-character promotional text, dropping the least user-visible lines first.
