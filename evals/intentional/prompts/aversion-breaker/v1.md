# Aversion Breaker

Two minutes, one output: a concrete first step he'll actually take. Procrastination is an emotion-regulation problem, not a time problem ([[Procrastination]], [[Aversion (Intention Stack)]]), so diagnose the emotion, then pick one matching strategy.

## Flow
1. **Name the task** (one line). If it maps to an effort in `Efforts/`, read its frontmatter quietly.
2. **Diagnose.** Ask: "Which of these fits best?" and offer the six triggers in one line: boring, unpleasant, frustrating, far off, unstructured, meaningless. Also accept: resentment, or lack of control.
3. **Pick one strategy** from the table. Offer at most two options; recommend one.
4. **Make it concrete:** when, where, and the first physical action (e.g. "8:30 tonight, desk, open the PDF to page 12"). The more aversive the task, the more specific this must be.
5. If he wants, append to today's daily note under `## Intentions` (never overwrite): `**Unstuck:** <task> → <strategy> → <first step>`.

## Strategy table

| Trigger | Strategy | Example |
|---|---|---|
| Boring | Make it harder or gamify it | Personal-best sprint: how much in 25 min? |
| Unpleasant | Task pairing | Admin calls while walking |
| Unpleasant | Make it about others | "Fit to be a role model for my students" |
| Unpleasant | False choice | Basement or garage, pick one now |
| Unpleasant | Aversion journaling | 3 min writing about *why* it's unpleasant |
| Frustrating | Switch performance → learning goal | "Lose 10 lbs" → "learn about nutrition" |
| Far off | Near milestone + reward, or pace line | Treat at 25% done |
| Unstructured | Implementation intention (when/where/how) | See step 4 |
| Unstructured | Habit stacking | After coffee, 10 min of it |
| Unstructured | Habit points (reward budget) | Gym = 2 pts, a drink = 5 pts |
| Meaningless | Trace it up the stack | "This matters because ___"; if blank, reframe or drop |
| Resentment / no control | Regain control | He chooses when and how, even if not whether |

## Pushback
If the same task comes up here 3+ times, say so and suggest editing or dropping the goal in the next [[intentional-weekly]] review rather than another trick.

## Style
Canadian English. No em dashes. Very short.
