# Intentional Daily

A 2 to 5 minute ritual. Morning sets three intentions; evening closes them. Based on [[Rule of Three]] and [[Intention Rituals]].

## Locating the vault
The vault root is the folder containing `CLAUDE.md` titled "LLM Wiki Agent Schema" (Calvin's Mindmap, normally `/Users/cference/Mindmap`). Follow that CLAUDE.md's constraints: never delete, never overwrite Calvin's prose, append only.

Files used:
- Today's note: `Calendar/Notes/Daily/YYYY-MM-DD.md` (create from `Atlas/Utilities/Templates/Daily Notes Template.md` if missing).
- This week's note: `Calendar/Notes/Weeks/YYYY-Www.md` (ISO week, e.g. `2026-W42.md`). May not exist.
- Active goals: `Efforts/Process Goals/` and `Efforts/Outcome Goals/` (frontmatter: desire, aversion, priority, values; body has RATE lines).

## Friction rules (most important)
Calvin has ADHD; small recurring friction kills rituals. So:
- Ask **at most three questions** per run. Prefer one.
- Never present more than three items, and never more than three bullet points in a reply. If he lists more, ask him to pick favourites and name the options inline in one sentence, not as a list. Put a when/where/first-action proposal on one line.
- Do the file work silently. Show him only the result.
- Never guilt-trip a miss. Goals are predictions; a miss is data.

## Mode: morning (default before ~2 pm, or when he says "plan my day")
1. Read this week's note (its Rule of Three) and skim active process goals. Read today's note if it exists.
2. Ask: **"By the time today is done, what three things will you want to have accomplished?"** If the weekly three exist, show them in one line above the question.
3. For each answer, silently check it ladders up: to a weekly three, a process goal, or a value. If one ladders to nothing, ask once: "This matters because ___?" Accept "it just needs doing".
4. If he flags one as dreaded (or its effort note has `aversion: High`), make it concrete: **when, where, and the first physical action**. If he didn't give all three, propose them yourself with real values ("1 pm, kitchen table, open the CRA folder"), ask him to confirm, and **stop: write nothing until he confirms**. If he already gave all three, skip the confirm and write.
5. Append to today's note (create the section if absent, never replace existing content):

```markdown
## Intentions
**Rule of Three**
- [ ] <item 1> ([[linked effort]] if any)
- [ ] <item 2>
- [ ] <item 3>

**Current intention:** <first one he'll start>
**First step for the dreaded one:** <when / where / first action>

## Distractions
```

## Mode: evening (after ~6 pm, or "close the day")
1. Read today's `## Intentions`.
2. Ask one question: "Which of the three got done?" Tick them.
3. For each miss, offer the six aversion triggers in one line (boring, unpleasant, frustrating, far off, unstructured, meaningless) or "prediction was off". Record his pick in one line. No lecture.
4. If a trigger repeats across 3+ days for the same effort, suggest running [[aversion-breaker]] or flag it for the weekly review.
5. Append under `## Intentions`:

```markdown
**Close-out:** 2/3. Missed: <item> (aversion: unstructured)
```

Do not touch the journal section or frontmatter fields (`meditated`, `alcohol`, `journaled`) unless he states them.

## Mid-day
"What am I doing?" or "reset": show the three, ask which is next, update **Current intention**. Log any urge he mentions under `## Distractions`.

## Style
Canadian English. No em dashes. Short.
