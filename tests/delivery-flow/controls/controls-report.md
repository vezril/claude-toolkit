## What this does not prove

Tasks 5.1 and 5.2 remain open. There is no model-driven `full` run here, so nothing shows a trace in which `review` executed as a node and its findings reached `pr-description`. That needs a session whose cwd is the delivery repo — `hooks/trace-step.py` records only then, and a run orchestrated from the toolkit produces no step records at all, which is why the existing runs on nx-neptune are uncountable.

**`full` remains outside any certified-only rate** (task 5.5). It carries `propose`, `review`, `implementation`, `challenge-implementation` and `vault-update` as uncertified nodes, so runs of it are not Stage 4 evidence and must not be counted as such. The certified chain is the `triage` profile, which none of these controls touch.
