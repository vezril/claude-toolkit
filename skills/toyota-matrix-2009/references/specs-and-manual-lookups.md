# 2009 Matrix XR 2.4L — platform facts & the must-verify numbers

Two tiers, kept apart:

- **Platform facts** — well-established, stable characteristics of the E140 Matrix / 2AZ-FE. Orientation, not the manual.
- **Must-verify numbers** — precision/safety-critical values I will **not** state from memory (a wrong oil grade, capacity, or torque is a real problem — and on this engine, oil is *especially* touchy). For each, this file says **where the real number lives**.

> **Sourcing honesty:** Toyota's owner's/repair manual wasn't machine-retrieved. Everything below that isn't recall data is general platform knowledge — a companion to your manual, not a replacement.

## Your configuration

**2009 Toyota Matrix XR, 2.4L** — second-generation (E140) Matrix, a tall compact hatch built at NUMMI and sold alongside its identical twin, the **Pontiac Vibe** (2009-2010). **"XR" is the Canadian-market mid trim** (the US line-up was Base / S / XRS) — so Canadian service literature and the Canadian recall database are your best-matched references.

- **Engine:** **2AZ-FE** — **2.4 L (2,362 cc)** DOHC 16-valve inline-4, aluminum block, **VVT-i**, port fuel injection. Roughly **158 hp / ~162 lb-ft** (2009 rating). Shared with the Camry, Corolla XRS, RAV4, tC/Scion — which is why its quirks (below) are so well documented.
- **Timing: chain, not belt.** The 2AZ-FE uses a **timing chain** → **no scheduled timing-belt replacement** (a common worry on a car this age — you don't have that maintenance item). *(Confident platform fact; still worth a glance in your maintenance schedule.)*
- **Transmission:** the 2.4L came with a **5-speed manual** or a **5-speed automatic** (the 1.8L base used a 4-speed auto). Confirm which you have — it changes the fluid and service.
- **Drivetrain:** **FWD** standard. **AWD** was offered on the 2.4L (uses a 4-speed auto, not the 5-speed) — **confirm whether yours is FWD or AWD**, because AWD adds driveline service (rear diff / coupling fluid) the FWD car doesn't have.
- **Fuel:** regular unleaded (87 octane) is the norm for the 2AZ-FE — confirm on the fuel door / manual.
- **OBD-II:** standard (2009) — the port is under the dash, driver's side. This matters for troubleshooting: **you can read fault codes yourself** with a cheap scanner (see the troubleshooting reference).

## ⚠️ Must-verify numbers — do NOT guess; here's where each lives

Deliberately blank rather than wrong. Look them up once and they're yours.

| What | Where to find it |
|---|---|
| **★ Engine oil grade & capacity** | Owner's manual → *Specifications*. **Get this exactly right** — the 2AZ-FE's oil spec was revised over its life (don't assume a grade), and this engine's oil-consumption tendency makes the correct grade + frequent level checks matter more than usual. Capacity differs with/without filter change. |
| **Oil-change interval** | Manual maintenance schedule. Given the oil-consumption issue, many owners check level **every fill-up** regardless of the change interval. |
| **Coolant type & capacity** | Manual → *Specifications*. Toyota uses a specific long-life coolant (don't mix types); correct coolant matters given the head-bolt/overheating history. |
| **Transmission fluid** (type + capacity) | Manual → depends on **manual vs. automatic** (and 5-speed vs. 4-speed AWD auto). Wrong ATF type causes shift problems. |
| **Tire size & pressure (cold)** | The **door-jamb placard** (driver's door) is authoritative for pressure; **sidewall** for size. Set cold. Safety-critical — never guess. |
| **Brake specs** (pad thickness, rotor min) | Repair manual. Safety-critical. |
| **Spark plugs** (type, gap, interval) | Manual → *Specifications*. The 2AZ-FE typically runs long-life iridium plugs — confirm type/interval, don't assume. |
| **Fastener torques** (lug nuts, drain plug, caliper, suspension) | Repair manual torque tables. **Lug-nut torque especially** — over/under-torquing wheels is a real hazard. |
| **Battery group size & spec** | Manual → *Specifications*, or the old battery's label. |
| **Fuse locations/ratings** | Manual → *Fuses*, and the fuse-box lid diagram. |
| **Fault (OBD-II) code meanings for a specific fix** | A scanner reads the **code**; see the troubleshooting reference for the DIY-read path. Interpreting a code into the right repair still often needs diagnosis. |

## Getting the authoritative source

- **Owner's manual:** Toyota Canada (toyota.ca → Owners) or Toyota's owner site — free PDF for the 2009 Matrix. Grab it; it has every spec above.
- **Repair procedures/torques:** a Toyota factory service manual, a Chilton/Haynes for the 2009 Matrix/Vibe, or a subscription service like ALLDATA/Mitchell. The **Pontiac Vibe** manual covers the same car.
- **Maintenance schedule:** in the owner's manual / the separate warranty-and-maintenance guide.
